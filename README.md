## 🌿 Tecnologías Core

Este laboratorio web está construido sobre un stack enfocado en el rendimiento gráfico y la fluidez interactiva:

* **WebGL / Three.js:** Renderizado acelerado por hardware para efectos visuales avanzados sin saturar la CPU.
* **GSAP (GreenSock):** Control y sincronización de las animaciones y transiciones de scroll.
* **Vite:** Herramienta de construcción ultra rápida para un flujo de desarrollo ágil.

## 📺 Bitácora de Avances
